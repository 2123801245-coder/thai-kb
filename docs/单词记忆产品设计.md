# 泰语单词记忆知识库 · 产品设计（认 / 读 / 写 / 用 四关 + FSRS）

> 目标不是"做题全对"，而是"合上书还能想起来、写出来、用出来"。
> 设计对象：现有 `泰语知识库` 的训练模块（词表 1198 词、词汇讲解 118 条、课文 25 篇已有例句与真人音频）。

---

## 一、产品逻辑流程图（文字版）

```
                      ┌─────────────────────────────┐
    新词入库 ────────▶ │ 词库 D0：待解锁（按词频/课序） │
                      └──────────────┬──────────────┘
                                     │  每天新词 8–12 个（可调）
                                     ▼
      ┌──────────────────── 学习流：四关闸门（Gate）────────────────────┐
      │  ① 认 ──▶ ② 读 ──▶ ③ 写 ──▶ ④ 用 ──▶ 全通过 = 掌握（可复习） │
      │  选择题        声调/跟读     听音默写     填空→造句             │
      │  （唯一允许    判定正确率   逐字符判定   按评分标准批改          │
      │   用选择的一关）                                                │
      └───────────────┬───────────────────────────────────────────────┘
                      │ 每关通过 → 该关生成一张 FSRS 卡（word×skill）
                      ▼
      ┌──────────────────── 复习引擎（每天一次）─────────────────────┐
      │ 1. 取到期卡：due <= today，按 (skill 关级, 逾期天数) 排序      │
      │ 2. 队列配比：到期卡 70% + 新词 30%，全程打乱（不按词表顺序）    │
      │ 3. 题型映射：卡在"认"→选择题；"写"→默写/拼写；"用"→填空/造句   │
      │ 4. 判分 1–4（Again/Hard/Good/Easy）→ FSRS 更新 S、D、R        │
      │ 5. 答错 → 立刻写错词本 + 明天强制重考 + 下次换题型             │
      │ 6. 连续两次同题型答对，才算该关"稳定"，否则退回上一题型难度     │
      └───────────────┬───────────────────────────────────────────────┘
                      ▼
      ┌──────────────────── 掌握看板 / 错词本 ──────────────────────┐
      │ 看板：认 X 词 · 读 Y 词 · 写 Z 词 · 用 W 词（四列分别统计）    │
      │       外加"认过但写不过"的差额 —— 这就是虚假记忆感的量化指标    │
      │ 错词本：按错误原因分组（拼写 / 声调 / 意思 / 搭配 / 语法 / 语序）│
      └──────────────────────────────────────────────────────────────┘
```

## 二、模块功能与交互细节

### 1. 词库（Lexicon）

**职责**：提供可调度的候选词与全部素材（释义、搭配、例句、音频、音节切分）。

字段（在现有 `data/words.json` 的 `{t,z,p,r,lesson}` 上扩展）：

| 字段 | 用途 | 为什么必须有 |
|---|---|---|
| `t` 泰语词、`z` 中文、`p` 词性、`r` 读音 | 展示 | — |
| `freq` 词频档、`level` 分级（1–5） | 排序与新词配比 | 先学高频词，让有限复习预算换最大可用词汇量 |
| `syl` 音节切分（如 `อ.พยพ` → `อบ-พะ-ยบ`） | 默写逐字符判分、拼写错定位 | 泰语无空格，判分必须先切音节才知道错在哪个音节 |
| `tone` 每音节声调 + `vlen` 长短元音 | 读关判定、声调错归类 | 声调错 ≠ 拼写错，纠错策略完全不同 |
| `cls` 量词、`colloc[]` 常用搭配 | 填空题的空位设计、造句评分点 | 泰语搭配（量词、介词、动词选择）是最容易"意思对但不像人话"的地方 |
| `ex[]` 例句（`{t,z,tier:口语/正式/书面,colloc,audio}`） | 语境复习 | 词必须寄生在句子里，孤词提取训练价值低 |
| `forms` 变体（不规则拼写、缩写） | 默写容错白名单 | 避免把 `จ.` / `จังหวัด` 判成错 |

**交互**：词库页只做"看素材"，不做掌握度判断；掌握度一律来自四关记录。

### 2. 学习流（四关闸门）

**硬规则（产品纪律，不可配置）**

1. **不许跳关**：`读` 未通过不能进 `写`，`写` 未通过不能进 `用`。
2. **认关只允许选择题，且只在新词第一次出现时使用**；此后同一词若再次出现选择题，不计入任何一关的"通过"。
3. **每关至少两种不同题型各通过一次**才升为"稳定"（单题通过只算"暂时通过"，24 小时后必须回炉一次）。
4. **答错不降关，但重置该关计时**：`写` 答错不影响已通过的 `认`，但该词 24 小时内必须重考 `写`。

**四关题型与判定**

| 关 | 主要题型 | 判定方式 | 泰语特化 |
|---|---|---|---|
| 认 | 图中/中文选泰语、泰语选中文（四选一） | 即时判定 | 干扰项优先取"同课近义词"与"拼写相近词"，避免送分 |
| 读 | 跟读录音 → 声调判分；听音 → 选出正确音节重音 | 与真人音频逐音节比声调型；容错 ±1 声调算"模糊" | 泰语 5 声调 + 长短元音，声调错直接判 Again |
| 写 | 听音默写（打字或手写）、看中文写泰语 | 逐字符 Levenshtein；音节级定位 | 声调符号 `่ ้ ๊ ๋` 漏写 = 声调错，不是拼写错 |
| 用 | 句子填空（无选项）→ 给出一个搭配 → 造句并批改 | 填空按目标词判定；造句按 4 项评分 | 量词、语序（修饰语后置）、助词/语气词是否自然 |

**造句评分标准（四项各 0–2 分，≥6 分算通过）**

1. 拼写与声调正确（2）
2. 词义用法落在该词的主流义项上（2）
3. 搭配/量词/介词自然（2）
4. 句子可理解且语法完整（2）

### 3. 复习引擎（FSRS per-skill）

**核心结构**：一条"卡" = `(word_id, skill)`，`skill ∈ {认, 读, 写, 用}`。
同一个词最多 4 张卡，各自有独立的 `S`（稳定度/天）、`D`（难度 1–10）、`R`（可提取性）、`due`。

**为什么不共用一张卡**：认得出来和写得出来是两条不同的记忆痕迹，共用会导致"选择题及格就把默写也推后 30 天"，正是虚假记忆感的来源。

**调度规则**

- 目标保留率 `R_target = 0.9`（可调 0.85–0.93）；`I = S / FACTOR × (R_target^(1/DECAY) − 1)`，FSRS-5/6 参数本地拟合，初期用默认权重。
- 四档映射：`Again`(1) 立即重来、`Hard`(2) 间隔 ×0.6、`Good`(3) 正常、`Easy`(4) ×1.3；`写`/`用` 关的 `Easy` 上限更保守（乘 1.15），因为产出型记忆更容易高估。
- 日上限：单日复习卡 ≤ 120 张；到期积压时按"逾期最久 + 关级最高"优先，宁可少而深。
- **混合打乱**：队列里新词、旧词、四种题型交叉排列，禁止同一词连续两题、禁止按课序/字母序。
- **错词换题型**：错一次 → 下次同词换"另一种题型 + 另一个例句"；错两次 → 降一档难度（如 `写` 从默写降到"补全缺字母"），连续两次答对再升回。

**队列构建伪代码**

```js
due  = cards.filter(c => c.due <= today && c.skill !== '认')  // 认关只在首日
newW = lexicon.pickNew(8)                                    // 词频优先
queue = interleave(shuffle(due).slice(0, 84), newW.map(w => firstSkillCard(w)), {ratio: 7/3})
queue = avoidSameWordAdjacent(queue)                         // 同词至少隔 6 题
```

### 4. 掌握看板（诚实反馈）

- 四列漏斗：**认 X → 读 Y → 写 Z → 用 W**，只显示通过"稳定"判定的词数。
- **虚假记忆指数**：`(X − Z) / X`，即"认得出来却写不出来"的比例；这个数才该被当成首要优化目标，而不是"已掌握 500 词"。
- 每关再分"暂时通过 / 稳定通过"两档，避免用一次蒙对刷数字。
- 只显示与用户自己上周的对比，不做跨用户排名（排名会把注意力推回"刷数字"）。

### 5. 错词本（按错误原因分类）

| 错误原因 | 判定来源 | 对应再练方式 |
|---|---|---|
| 拼写错 | 默写字符错误（非声调位） | 音节拼块重组、逐步遮字 |
| 声调/长短元音错 | 声调符号或元音长度错 | 跟读 + 声调对比最小对立对（如 `ขา/ค่า/ค้า`） |
| 意思错 | 选择题或填空选错义项 | 中文→泰语反向题 + 例句语境题 |
| 搭配错 | 填空/造句中搭配不自然 | 搭配卡（只考 `colloc`），给半句补全 |
| 语法/语序错 | 造句批改指出 | 语序重排题（给词块让用户排序） |

每条记录保存：`word_id, skill, 题型, 用户答案, 正确答案, 错误类型, 时间`；错词本按"错误类型"分组显示，点进去直接开始一组同类专项。

## 三、一个词的完整学习路径（示例：`อพยพ` 迁徙/撤离）

| 天 | 关 | 题型 | 用户动作 | 判定与调度 |
|---|---|---|---|---|
| D1 | 认 | 四选一：`อพยพ` = ? | 选"撤离、迁移" | Good → 认卡 S=1.0、due=D3；解锁"读" |
| D1 | 读 | 听音跟读 2 音节，声调型 `อบ-พะ-ยบ`（中-短-中） | 录音，第 2 音节读成高调 | Hard（声调偏差 ±1）→ 读卡 S=0.6、due=D2，标"声调待稳" |
| D2 | 读 | 最小对立对：`อพยพ / อบรม` 听辨 + 复读 | 两题全对 | Good → 读卡 S=2.4、due=D5；解锁"写" |
| D2 | 写 | 听音默写（不给字） | 写 `อพยบ` | Again：末辅音 `พ`→`บ` 拼写错 → 写卡 S=0.4、due=D3（明天强制），错词本记"拼写错" |
| D3 | 写 | **换题型**：补全缺字母 `อ_พย_` | 全对 | Good → S=1.8、due=D6 |
| D3 | 写 | 看中文写泰语："撤离" | 全对 | Easy → S=3.5、due=D12，写关升"稳定"；解锁"用" |
| D4 | 用 | 句子填空（无选项）：`น้ำท่วมหนัก ทางการต้อง ____ ประชาชนออกจากพื้นที่` | 填 `อพยพ` | Good → 用卡 S=1.5、due=D8 |
| D4 | 用 | 造句：用 `อพยพ` 说一句 | "ประชาชนอพยพออกจากหมู่บ้านเพราะน้ำท่วม" | 评分 8/8 → Easy → S=3.0、due=D15 |
| D6 | 复习 | 写：默写 `อพยพ` | 全对 | Good → S≈5、due≈D20 |
| D8 | 复习 | 用：**换例句**造句（正式场合：`ทางการได้อพยพผู้ประสบภัย...`） | 通过 | Good → S≈7 |
| D20+ | 复习 | 四关按各自 due 轮转；任关答错 → 该关 S 折半、due 拉回 D+1 | — | 稳定期后间隔 ≥ 60 天，全部四关稳定 3 次 = 标记"完全掌握"（仍保留低频抽查） |

关键点：`认` 早在 D3 就稳定了，但看板此刻仍显示"写 0、用 0"，用户不会误以为自己会了。

## 四、数据库表结构（SQLite / 也可落成 JSON）

```sql
-- 词条
CREATE TABLE words (
  id            INTEGER PRIMARY KEY,
  th            TEXT NOT NULL UNIQUE,     -- 泰语拼写
  zh            TEXT NOT NULL,            -- 中文
  pos           TEXT,                     -- 词性
  roman         TEXT,                     -- 读音
  level         INTEGER DEFAULT 1,
  freq_rank     INTEGER,
  syllables     TEXT,                     -- JSON: [{"t":"อบ","tone":"中","vlen":"短"},...]
  classifier    TEXT,
  collocations  TEXT,                     -- JSON: ["อพยพประชาชน","อพยพหนีภัย"]
  lesson        TEXT,
  created_at    TEXT DEFAULT (datetime('now'))
);

-- 例句（一档一例：口语/正式/书面）
CREATE TABLE examples (
  id        INTEGER PRIMARY KEY,
  word_id   INTEGER NOT NULL REFERENCES words(id),
  th        TEXT NOT NULL,
  zh        TEXT NOT NULL,
  tier      TEXT CHECK (tier IN ('口语','正式','书面')),
  colloc    TEXT,                          -- 本句体现的搭配
  audio     TEXT,                          -- audio/<id>_ex.mp3
  UNIQUE(word_id, tier)
);

-- 掌握记录：word × skill 一张卡
CREATE TABLE cards (
  id           INTEGER PRIMARY KEY,
  user_id      TEXT NOT NULL,
  word_id      INTEGER NOT NULL REFERENCES words(id),
  skill        TEXT NOT NULL CHECK (skill IN ('认','读','写','用')),
  state        TEXT NOT NULL DEFAULT 'new',  -- new/learning/review/stable
  stability    REAL,      -- FSRS S（天）
  difficulty   REAL,      -- FSRS D（1–10）
  retrievability REAL,    -- FSRS R（0–1，展示用，随时重算）
  reps         INTEGER DEFAULT 0,
  lapses       INTEGER DEFAULT 0,
  last_grade   INTEGER,
  last_review  TEXT,
  due          TEXT,
  pass_count   INTEGER DEFAULT 0,   -- 该关"稳定通过"次数
  UNIQUE(user_id, word_id, skill)
);

-- 复习记录（全量，用于拟合 FSRS 参数与复盘）
CREATE TABLE reviews (
  id          INTEGER PRIMARY KEY,
  user_id     TEXT NOT NULL,
  card_id     INTEGER NOT NULL REFERENCES cards(id),
  ts          TEXT NOT NULL,
  grade       INTEGER NOT NULL,      -- 1 Again / 2 Hard / 3 Good / 4 Easy
  question_type TEXT NOT NULL,       -- 听音默写/看中文写泰语/填空/造句/选择
  elapsed_ms  INTEGER,
  answer      TEXT,
  expected    TEXT,
  prev_stability REAL,
  prev_difficulty REAL,              -- 存一份，便于离线重算
  next_stability REAL,
  next_difficulty REAL
);

-- 错词（错误原因分类）
CREATE TABLE mistakes (
  id          INTEGER PRIMARY KEY,
  user_id     TEXT NOT NULL,
  word_id     INTEGER NOT NULL REFERENCES words(id),
  skill       TEXT NOT NULL,
  reason      TEXT NOT NULL CHECK (reason IN ('拼写','声调','意思','搭配','语法','语序')),
  question_type TEXT,
  answer      TEXT,
  expected    TEXT,
  resolved    INTEGER DEFAULT 0,     -- 同类专项连对 2 次后置 1
  created_at  TEXT DEFAULT (datetime('now'))
);

-- 造句与批改（用关的原始素材）
CREATE TABLE sentences (
  id        INTEGER PRIMARY KEY,
  user_id   TEXT NOT NULL,
  word_id   INTEGER NOT NULL REFERENCES words(id),
  text      TEXT NOT NULL,
  score_spelling INTEGER, score_meaning INTEGER,
  score_colloc   INTEGER, score_grammar INTEGER,
  feedback  TEXT,                    -- 批改意见
  corrected TEXT,                    -- 正确版本
  created_at TEXT DEFAULT (datetime('now'))
);

-- 每日会话（看板与"每日新词"预算）
CREATE TABLE sessions (
  id INTEGER PRIMARY KEY, user_id TEXT NOT NULL, day TEXT NOT NULL,
  new_words INTEGER, reviews_done INTEGER, reviews_due INTEGER,
  accuracy REAL, streak INTEGER,
  UNIQUE(user_id, day)
);

CREATE INDEX idx_cards_due ON cards(user_id, due);
CREATE INDEX idx_mistakes_word ON mistakes(user_id, word_id, resolved);
```

**与现有工程对应**

| 本设计 | 现有文件/键 | 迁移动作 |
|---|---|---|
| `words` | `data/words.json`（1198 条，`{t,z,p,r,lesson}`） | 加 `syllables/collocations/level/freq_rank`，其余原样 |
| `examples` | `data/sents.json`、`vok.json.sents`、`words.ex` | 统一成 `{th,zh,tier,colloc,audio}`，缺 `tier` 的先按课文层级推 |
| `cards/reviews` | `localStorage: kb_fc`、`kb_fc_log`（SM-2） | 置 `kb_fsrs_v1`，对 `kb_fc` 做一次迁移：`i`→`stability` 初值、`l`→`last_grade`、`n`→`reps` |
| 音频 | `data/audio-manifest.json` + `audio/`（1722 文件） | 读关直接复用；写关不需要音频 |
| 看板 | 首页统计 | 换成四列漏斗 + 虚假记忆指数 |

## 五、记忆科学依据（逐条对应）

| 设计 | 依据 | 直接影响的产品决定 |
|---|---|---|
| 四关必须全通过才算掌握 | **线索依赖的提取**：记忆与提取线索绑定，被训练的是"线索→答案"这条通路。选择题训练的是"四选一的再认线索"，与"凭空产出"不是同一条通路（Tulving & Pearlstone, 1966 可得性 vs 可及性） | 所以"认得"不能折算为"会写"，四关各自建卡、各自调度 |
| 测试以提取为主、选择题只用于首日 | **测验效应 / 提取练习**：同等时间下，做提取比重复阅读的长期留存高得多（Roediger & Karpicke, 2006） | 新词首日给"认"是因为还没有可提取的痕迹；一旦有了，就必须撤掉选项 |
| 默写、造句这类产出型任务 | **生成效应 + 产出效应**：自己生成答案（而非挑选）记得更牢（Slamecka & Graf, 1978；MacLeod et al., 2010 出声/书写产出优势） | 写关用默写而非"选拼写"，用关用造句而非"选正确句子" |
| 间隔按掌握度动态拉长/缩短 | **间隔效应 + 期望遗忘**：在遗忘临界点复习的收益最大；FSRS 用 DSR 模型把"该什么时候复习"变成可计算量（Ye, 2022+；FSRS 为 Anki 现行调度器） | 用 FSRS 而不是固定 1/3/7 天；四档评分决定 S 的乘数 |
| 答错立刻缩短到第二天 | **失败后的重学成本**：错误若不在 24 小时内纠正，错误记忆会被再次巩固（提取失败本身也会形成"我好像不会"的抑制） | `Again` → due=+1 天，并强制换题型 |
| 错词换题型、换例句 | **编码变异性**：同一材料在多种情境下提取，会形成多条独立线索，抗遗忘更强（Bjork & Bjork 的 desirable difficulties） | 同词错后不再出原题；每个词备 3 档例句正好支撑换句子 |
| 新词旧词打乱、不按词表顺序 | **交错练习**：混合训练比分组块训练迁移更好，且能防止"按顺序背下来"的顺序线索（Rohrer & Taylor, 2007） | 队列构建时强制 `avoidSameWordAdjacent` + 跨课交叉 |
| 看板四关分开、不给"已掌握 N 词" | **元认知校准**：单一总分会让学习者高估自己（Koriat & Bjork, 2005 预见性判断偏差），高估直接减少后续投入 | 显示"认 X / 写 Z"和差额指数，把落差摆到明面上 |
| 每关要"两种题型各通过一次"才稳定 | **迁移适当加工**：单一题型的通过可能只是题型特异的学习（transfer-appropriate processing） | 防"同一题型刷三次"刷出假稳定 |

## 六、三个可复用提示词（已按 `อพยพ` 填好示例）

### A. 生成三档例句

> 给泰语单词 `อพยพ` 生成 3 个例句，难度递进（日常口语 → 正式场合 → 书面语），每句标注中文翻译，并指出该词在句中的常见搭配。输出 JSON：`[{tier, th, zh, colloc}]`。

**期望输出示例**

| 档 | 泰语 | 中文 | 搭配 |
|---|---|---|---|
| 口语 | `ครอบครัวเขาอพยพไปอยู่ต่างจังหวัด` | 他家搬去外府住了 | `อพยพไปอยู่…` |
| 正式 | `ทางการต้องอพยพประชาชนออกจากพื้นที่น้ำท่วม` | 官方必须把民众撤离洪区 | `อพยพประชาชนออกจาก…` |
| 书面 | `การอพยพของผู้ลี้ภัยเป็นปรากฏการณ์ที่ต่อเนื่องมาหลายทศวรรษ` | 难民迁徙是持续数十年的现象 | `การอพยพของ…`（名词化） |

### B. 生成四道不同题型的测试

> 针对 `อพยพ` 生成 4 道不同题型的题：1 道听音默写、1 道看中文写泰语、1 道句子填空、1 道造句。填空题不给选项，造句题给出评分标准。

- 听音默写：播放 `อพยพ`（`audio/<id>_word.mp3`），要求输入拼写与声调符号。
- 看中文写泰语：`撤离、迁移 → ______`。
- 句子填空：`น้ำท่วมหนัก ทางการต้อง ______ ประชาชนออกจากพื้นที่`（不给选项，只给语境）。
- 造句：用 `อพยพ` 写一句关于"灾害撤离"的话；评分：拼写声调 2 + 义项 2 + 搭配 2 + 语法完整 2，≥6 通过。

### C. 造句批改

> 用户用 `อพยพ` 造的句子是：`"ประชาชนอพยพออกจากหมู่บ้านเพราะน้ำท่วม"`。判断拼写、语法、搭配是否自然；有错先指出错误，再给正确版本，最后一句话解释为什么。

- 拼写：正确（`อพ-พยพ`，无多余声调符号）
- 语法：正确（主谓 + `ออกจาก` 处所 + `เพราะ` 原因从句）
- 搭配：自然（`อพยพออกจาก…` 是常用搭配；若写 `อพยพบ้าน` 则搭配错，应为 `ย้ายบ้าน`）
- 结论：可用。若想更像书面语，可换成 `การอพยพของชาวบ้าน...`。
