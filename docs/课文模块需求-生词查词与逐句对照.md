# 课文模块需求：生词点按查词 · 汉泰逐句对照

迭代范围：仅「课文（บทอ่าน）」模块 · 读者：移动端 / 前端开发、测试、内容编辑 · v1.0

## 一、功能概述

本次只改「课文（บทอ่าน）」模块的两处能力，其余页面及其数据一律不动：

1. **生词点按查词（แตะคำศัพท์ใหม่เพื่อดูคำอธิบาย）**：点按课文中已标注的生词（คำศัพท์ใหม่），就地唤起释义卡片（การ์ดคำอธิบาย）。
2. **汉泰逐句对照（เทียบประโยคจีน–ไทย）**：取消整段翻译，改为中泰逐句一一对应。

词条复用现有词表与包内发音，不新增数据源，均离线可用。

## 二、交互流程

**A. 点按查词**
1. 点按正文中带下划点线的生词。
2. 就地唤起卡片：词下方空间足够则内联展开，不足则居中浮层。
3. 卡片依次显示：泰语词 → 读音（คำอ่าน）+ 发音按钮 → 词性（ชนิดคำ）→ 中文释义（ความหมาย）→ 常用搭配 → 例句（含中文）。
4. 一词多义时按词性分组，默认高亮与本课语境一致的义项，其余可展开。
5. 关闭方式四种任一：再次点按该词、点按卡片外区域、点按「关闭（ปิด）」、下滑卡片。
6. 关闭后保持原阅读位置与进度，不跳动。
7. 手势区分：单击＝查词；长按 ≥ 500 毫秒＝文本选择（不查词）；拖动＝滚动（不触发）。
8. 段落发音、逐句跟读的点击区域优先，生词命中区不覆盖其上。

**B. 逐句对照**
1. 默认只显示泰文正文。
2. 打开「逐句对照（เทียบทีละประโยค）」开关后，每段泰文下方逐句显示对应中文。
3. 就地重排，不重新取数，保持滚动位置；开关状态本地记忆。

## 三、字段说明表

| 字段名 | 类型 | 是否必填 | 说明 |
|---|---|---|---|
| 泰语词（คำศัพท์） | 字符串 | 必填 | 须与课文标注一致，作查词主键 |
| 读音（คำอ่าน） | 字符串 | 选填 | 罗马转写或音标。**现有 559 条词目中仅 128 条有值**，缺失时隐藏该行；内容侧按此要求补录 |
| 发音（เสียงอ่าน） | 音频 | 选填 | 优先包内音频（已覆盖全部词目）；缺失降级系统泰语语音，再失败静默 |
| 词性（ชนิดคำ） | 枚举 | 必填 | น. / ก. / ว. / บ. 等，写法与词表、词汇讲解一致 |
| 中文释义（ความหมาย） | 字符串 | 必填 | 多义项分条，本课语境义项置顶 |
| 常用搭配（คำที่มักใช้ร่วม） | 字符串数组 | 选填 | 每项 ≤ 20 字、最多 3 项，无则隐藏 |
| 例句（ประโยคตัวอย่าง） | 对象数组 | 选填 | 每项含泰文句与中文句，无则隐藏 |
| 句对（คู่ประโยค） | 对象 | 必填 | {序号, 泰文句, 中文句}，中泰序号一一对应 |
| 对照开关（สวิตช์เทียบประโยค） | 布尔 | 必填 | 默认关闭，沿用上次选择 |

**界面文案（中文 / 泰文）**：生词 / คำศัพท์；读音 / คำอ่าน；词性 / ชนิดคำ；释义 / ความหมาย；常用搭配 / คำที่มักใช้ร่วม；例句 / ประโยคตัวอย่าง；关闭 / ปิด；暂无释义 / ยังไม่มีคำอธิบาย；加入我的生词 / เพิ่มในคำศัพท์ของฉัน。

## 四、边界与异常

- **断句**：泰文按句末空格与终止符号切分，中文按「。！？；」切分，每段两侧句数须相等；不等时按段对齐并标注「合并句」。
- **未收录词**：显示「暂无释义」，提供「加入我的生词」，不发起网络请求。
- **一词多义**：义项顺序稳定；同词在不同课文高亮不同义项时以数据标注为准。
- **离线**：查词与对照数据随包发布，飞行模式功能完整；发音降级不影响卡片信息。
- **性能**：最长课文 64 段，惰性渲染，首屏只渲染可视区前后各 3 段；卡片单实例。滚动保持 60fps，内存增量 ≤ 30MB。
- **可读性**：泰文 16sp / 行高 1.7，中文对照 14sp、次级色、行高 1.7，段间距 ≥ 16dp；字号跟随全局设置。
- **术语一致性**：卡片字段名与「词表」「词汇讲解」完全一致。
- **异常兜底**：数据缺失或解析失败时退化为纯泰文 + 整段对照（旧行为），不得白屏或报错。

## 五、验收清单

- [ ] 点按任一已标注生词，300 毫秒内唤起释义卡片
- [ ] 卡片必含泰语词、读音、词性、中文释义；搭配与例句有则显示，无则不出现空行
- [ ] 点按发音按钮可听到读音，断网时仍可播放
- [ ] 再次点按该词、点按卡片外区域、点按关闭、下滑卡片，四种方式均可关闭且阅读位置不变
- [ ] 长按生词进入文本选择，不唤起卡片
- [ ] 一词多义按词性分组，切换义项不刷新页面、不丢滚动位置
- [ ] 未收录词显示「暂无释义」并出现「加入我的生词」，无空白或异常提示
- [ ] 打开逐句对照后中泰句数一致、逐句对齐，无错行、错位、漏句
- [ ] 对照开关状态退出重进后保持，切换时滚动位置不跳动
- [ ] 飞行模式下点按查词与逐句对照均可用
- [ ] 64 段长课文滚动到底无卡顿、无白屏，内存增量 ≤ 30MB
- [ ] 卡片字段命名与「词表」「词汇讲解」一致
