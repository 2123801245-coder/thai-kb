# thai-kb

泰语个人知识库：本地静态页面（`泰语个人知识库.html`）+ 数据（`data/`）+ 模块（`js/`）。

## 三种打开方式

| 场景 | 怎么做 |
|---|---|
| 给同学的离线版 | 双击「一键发版（Mac）.command」，或 `node tools/release.js`：自检 → 打包 → 压缩一条龙，产出 `~/Desktop/泰语知识库-发布版` 与 `泰语知识库-离线版.zip`；桌面上有上一版 zip 时还会自动生成增量「更新包」 |
| 开发（改了 `data/` 或 `js/`） | `python3 server.py` → http://127.0.0.1:8765 |
| 手机 / 平板 | `python3 server.py 8765 --lan`，手机连同一个 Wi-Fi 打开终端里列出的网址 |

- 局域网模式根路径是一个手机友好的入口页，点一下进知识库；
  用网址打开时笔记、图片、掌握度都能正常存在手机上，而手机直接开文件
  （`file://`）时 iOS Safari 不让网页存数据。公共 Wi-Fi 下不要开这个模式。
- `--lan` 会跳过 `198.18.0.0/15` 这类 TUN / 代理网卡的地址（开着 VPN 时
  「连一下 8.8.8.8」拿到的往往是这种手机连不上的地址），并按像不像家用网段排序。

## 界面适配

桌面 / 手机 / 平板自适应，桌面端行为不变：

- 窄屏（≤820px）顶栏改为 fixed，滚动后收起只留标签条（含标签条横向滚动居中）
- 手机上词表改成「泰语词 + 掌握度 ／ 中文释义 ／ 词性·读音·来源」三行卡片式
- 触摸目标 ≥44px、输入框字号 ≥16px（否则 iOS 聚焦会自动放大整页）
- 笔记图片在触屏上用 ◀ ▶ 调顺序（HTML5 拖放触屏不触发）
- `viewport-fit=cover` + `env(safe-area-inset-*)`：刘海屏 / 底部小白条不裁切

细节与回归要求见 `js/README.txt`。
