【为什么要合并】
APK 总共约 {{sizeMb}}，Gitee 单个附件不能超过 100 MB，所以切成了 {{parts}} 片。
下载后合并即可，脚本会自动校验，不会装到坏文件。


【怎么装 · Windows】
1. 在下载页面把这些文件下到**同一个文件夹**：
      thai-kb.apk.part1 ~ thai-kb.apk.part{{parts}}
      合并安装（Windows）.bat
2. 双击「合并安装（Windows）.bat」
3. 窗口里会显示 SHA-256，应等于：
      {{sha256}}
   一致 = 文件完好；不一致 = 分片没下全，删掉重下。
4. 同文件夹里出现 thai-kb.apk，把它发到手机（微信/QQ/数据线都行）
5. 手机上点开安装，提示「未知来源」时选允许


【怎么装 · Mac】
1. 同样把 {{parts}} 个 part + 「合并安装（Mac）.command」下到同一个文件夹
2. 双击「合并安装（Mac）.command」
   （若提示无法打开，右键 → 打开 → 仍要打开）
3. 它会生成 thai-kb.apk 并显示 SHA-256，核对同上
4. 用 AirDrop / 数据线把 APK 传到安卓手机安装


【只想手动合并（不想跑脚本）】
Windows 命令行：
    copy /b thai-kb.apk.part1+thai-kb.apk.part2+…+thai-kb.apk.part{{parts}} thai-kb.apk
Mac / Linux 终端：
    cat thai-kb.apk.part* > thai-kb.apk


【常见问题】
· 装的时候提示「应用未安装」：多半是分片没下全，重新合并并核对 SHA-256。
· 手机上打不开安装包：确认下的是合并后的 thai-kb.apk，不是 part 文件。
· 已经装过旧版：直接覆盖安装即可，App 里的学习记录（掌握度、错题本、笔记）不会丢。
· 这个包是全量离线的，装上后不需要联网，也不依赖任何网站。
· App 里「关于」页有「🔄 立即检查更新」，也能直接跳到下载页。
