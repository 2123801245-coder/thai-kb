泰语知识库 · iPhone / iPad 打开步骤
（发这个文件和一个 泰语知识库-离线版-1.8.2.zip 过去就行）

一、先把包传过去
  包约 580MB，微信传不动（超 100MB 会被拦）。用网盘、QQ 传文件、
  AirDrop 或者 U 盘拷。传到 iPhone 后它会落在「文件」App 的「下载」里。

二、装一个 iSH（免费，App Store 搜 iSH）
  为什么一定要它：iOS 的 Safari 不能直接打开本地网页文件，
  从「文件」点开 html 只是只读预览，笔记和掌握度都存不住。
  iSH 是一个跑在手机里的 Linux，用它开一个只在本机的小网站，
  Safari 用 localhost 访问就正常了。数据全部留在这台手机上。

三、解压
  在「文件」里长按 zip → 解压，得到一个「泰语知识库-发布版」文件夹。
  别改名，也别把里面的 data / media / audio 拆出来单独放。

四、起服务（打开 iSH，一行一行输入，每行回车）
  apk add python3
      等它下载完，约 1 分钟，最后出现 OK 就行。
  mkdir -p /mnt/kb
  mount -t ios . /mnt/kb
      这行回车后会弹出 iOS 的文件选择器：
      选中刚才解压出来的「泰语知识库-发布版」文件夹 → 点「打开 / 完成」。
  cd /mnt/kb && python3 -m http.server 8765
      看到 Serving HTTP on 0.0.0.0 port 8765 就成功了。

五、打开
  切到 Safari，地址栏输入：http://localhost:8765
  会看到「📖 打开知识库」的入口，点进去就是用。
  想要桌面图标：Safari 底部「分享」→「添加到主屏幕」，以后点图标直接用
  （图标打开前 iSH 里的服务要还在跑）。

六、注意事项
  · iSH 要留在后台别关；锁屏太久或切走很久，iOS 会把它挂起，
    回来后重新走第四步的 mount 和起服务两行命令即可。
  · iSH 里刷出几行 FIXME: socketcall 之类的提示，是正常现象，不影响用。
  · 进度（掌握度、笔记、错题本）存在 Safari 里，重启手机也不会丢。
  · 换 WiFi、开飞行模式都不影响，因为访问的是本机地址。
  · 实在不想装 iSH：让同学用 Android 或电脑开一次服务，
    iPhone 输那台机器的局域网地址也能用（见 使用说明.txt 方式二）；
    或者用页面底部的「导出备份 / 导入备份」手动搬进度。
