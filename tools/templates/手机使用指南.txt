泰语个人知识库 · 手机 / 平板使用指南
========================================

结论先说：手机上不用电脑也能用，但 Android 和 iPhone / iPad 难度差很多。

────────────────────────────────
一、Android —— 最省事，完全不用电脑
────────────────────────────────
1. 把「泰语知识库-离线版.zip」发到手机（微信 / QQ / 网盘都行）；
2. 在手机上解压；
3. 打开文件管理器，进到解压出来的文件夹，点「{{html}}」，
   选「用浏览器 / Chrome 打开」。
   ✅ 用浏览器打开本地文件时存储是正常的：掌握度标记、笔记、错题本、
      阅读位置都存得住（我在 Chrome 里实测过 localStorage 与 IndexedDB 都可用）。
   · 如果点开只看到一堆代码，说明是当成文本打开了：长按文件 →
     打开方式 → 选浏览器。
   · 如果打开后页面底部出现「存不住数据」的横幅，说明你这台机器
     不允许，请改用办法三。

────────────────────────────────
二、iPhone / iPad —— 手机上要有个「本地服务器」App
────────────────────────────────
iOS 的 Safari 不能直接打开本地文件，从「文件」App 点开 HTML 只是受限预览，
网页存不了数据（笔记、掌握度都会丢）。所以要在手机上装一个能起本地服务的 App：

1. App Store 搜「iSH」（免费，Alpine Linux 环境）装一个。
   ⚠️ 别用「a-Shell」：它是 WebAssembly 实现、没有 socket，
   `python3 -m http.server` 在那里起不来，只能当文件浏览器用。
2. 先在「文件」App 里把「泰语知识库-离线版.zip」解压好（得到「泰语知识库-发布版」文件夹）。
3. 打开 iSH，依次输入（每行回车一条）：
       apk add python3
       mkdir -p /mnt/kb
       mount -t ios . /mnt/kb
   输入 mount 那行后会弹出 iOS 的文件选择器：选中解压出来的
   「泰语知识库-发布版」文件夹，点「打开 / 完成」。
   （每次重开 iSH 都要重新 mount 一次，这是 iOS 的限制。）
4. 挂好之后起服务：
       cd /mnt/kb && python3 -m http.server 8765
   看到「Serving HTTP on 0.0.0.0 port 8765」就成功了，iSH 要一直开着别切走。
5. 切到 Safari，地址栏输 http://localhost:8765 —— 看到「📖 打开知识库」
   按钮点进去即可。这样是正常网址，数据能存住，还能「分享 → 添加到主屏幕」
   变成桌面图标。

⚠️ iSH 里可能会刷出几行 "FIXME: socketcall" 之类的日志，不影响使用；
   切到后台太久 iOS 会杀掉 iSH，回来时重新 mount + 起服务即可，
   已经存下的进度不会丢。卡住就用办法三，最稳。

────────────────────────────────
三、iOS 兜底：手动备份（不需要装任何 App）
────────────────────────────────
接受"存不住"，用备份文件记进度：
  · 学完在页面底部点「💾 导出备份」→ 存成一个 .json 文件；
  · 下次打开在「➕ 添加」页点「📥 导入备份」→ 选那个文件，进度就回来了。
页面一旦发现存不住数据，会自动在底部挂一条横幅提醒，横幅上就有这两个按钮。

────────────────────────────────
四、班里同学混着用怎么办
────────────────────────────────
· Android 同学：把 zip 发过去，让他按办法一自己打开，不用你管；
· iPhone 同学：
  - 让他装个本地服务器 App 走办法二；或
  - 用任何一台 Android 手机 / 电脑开一次服务，iPhone 用浏览器输网址进
    （见 使用说明.txt「方式二：手机 / 平板访问」）；或
  - 走办法三，用备份文件记进度。

────────────────────────────────
五、为什么不放到网上
────────────────────────────────
传到 GitHub Pages / 网盘直链确实最省事，手机点开就能用，但那样教材和音频
就离开你的电脑、进了别人的服务器了。使用说明里写明「请勿外传」，
所以不提供这条路 —— 请不要把本文件夹传到任何公开平台。
